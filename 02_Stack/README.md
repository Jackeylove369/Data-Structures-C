## 详细功能说明

栈是一种**后进先出（LIFO, Last In First Out）**的线性表，只允许在一端（栈顶）进行插入和删除操作。本项目分别用“数组”和“链表”实现了这两种栈。

### 1. 顺序栈（SqStack）
顺序栈本质是一段连续的内存空间加上一个栈顶指针（数组下标）。

**核心特性：**
- **存储方式**：静态数组 `data[MaxSize]`。
- **栈顶指针**：`top` 指向栈顶元素，初始化为 `-1` 表示空栈。
- **随机访问**：支持 O(1) 时间复杂度读取栈顶元素。
- **容量限制**：受 `MaxSize` 限制，存在“栈满”（上溢）的情况。

**提供的操作：**
- `InitStack`：初始化空栈，令 `top = -1`。
- `StackEmpty`：判断栈是否为空。
- `StackFull`：判断栈是否已满。
- `StackLength`：返回栈内元素个数（`top + 1`）。
- `Push`：入栈，先判断是否栈满，再执行 `data[++top] = e`（先加后放）。
- `Pop`：出栈，先判断是否栈空，再执行 `e = data[top--]`（先取后减）。
- `GetTop`：读取栈顶元素，只读不删，不改变 `top`。
- `SqPrint`：打印顺序栈（从左到右依次为栈顶到栈底）。

### 2. 链栈（LiStack）
链栈采用不带头结点的单链表实现，栈顶指针即链表头指针。

**核心特性：**
- **存储方式**：动态申请结点，内存不连续。
- **栈顶指针**：`S` 直接指向栈顶结点，初始化为 `NULL` 表示空栈。
- **动态扩展**：只要内存足够，不会出现“栈满”的情况。
- **操作限制**：入栈和出栈都在链表头部进行（头插法和头删法），时间复杂度均为 O(1)。

**提供的操作：**
- `LiInit`：初始化空栈，令 `*S = NULL`。
- `LiEmpty`：判断链栈是否为空（`S == NULL`）。
- `LiLength`：遍历链表，统计元素个数。
- `LiPush`：入栈，采用**头插法**将新结点插入链表头部。
- `LiPop`：出栈，采用**头删法**删除栈顶结点，并 `free` 释放内存。
- `LiGetTop`：读取栈顶元素，只读不删。
- `LiPrint`：打印链栈（从左到右依次为栈顶到栈底）。
