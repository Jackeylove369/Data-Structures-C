# 数据结构基础：顺序表与单链表完整实现

本项目使用 C 语言实现了线性表的两种基本存储结构：**顺序表（Sequential List）** 和 **单链表（Singly Linked List）**。代码包含详细的注释，涵盖初始化、插入、删除、查找、遍历及内存释放等核心操作，适合数据结构初学者复习参考。

## 文件结构

本项目由三个独立的源文件组成：

| 文件名 | 说明 |
| :--- | :--- |
| `SqList.c` | 顺序表（静态数组实现） |
| `LinkList_HeadInsert.c` | 单链表（带头结点）—— **头插法** |
| `LinkList_TailInsert.c` | 单链表（带头结点）—— **尾插法** |

---

## 详细功能说明

### 1. 顺序表 `SqList.c`
顺序表本质是一段连续的内存空间加上一个长度计数器，支持随机访问。

**核心特性：**
- **随机存取**：只要知道下标，就能以 O(1) 的时间复杂度直接定位元素。
- **插入/删除**：需要搬动后续元素，平均时间复杂度为 O(n)。

**提供的操作：**
- `InitList`：初始化空表。
- `GetByIndex`：按下标取值（0 ~ length-1）。
- `GetByPos`：**按位序取值**（1 ~ length），注意位序与下标的转换（位序 = 下标 + 1）。
- `InsertByIndex`：按下标插入，核心逻辑是从后往前搬移元素腾出空位。
- `DeleteByIndex`：按下标删除，核心逻辑是从前往后搬移元素覆盖待删位置。
- `FindByValue`：按值查找，返回第一个匹配元素的下标。
- `Print` / `ShowIndexRule`：格式化打印表格，直观展示“下标”与“位序”的对应关系。

### 2. 单链表（头插法） `LinkList_HeadInsert.c`
采用带头结点的单链表结构。头插法是将新结点插入到头结点之后、原首结点之前。

**核心特性：**
- 插入操作无需遍历链表，时间复杂度为 O(1)。
- **重要特性**：头插法会导致链表顺序**完全逆序**（例如依次插入 10, 20, 30, 40，结果变为 40 -> 30 -> 20 -> 10）。

**提供的操作：**
- `InitList`：创建头结点，返回头指针。
- `HeadInsert`：在链表头部插入新结点。
- `Print`：遍历并打印链表。
- `Length`：统计数据结点个数（不含头结点）。
- `DestroyList`：释放所有结点内存，防止内存泄漏。

### 3. 单链表（尾插法） `LinkList_TailInsert.c`
同样是带头结点的单链表，但增加了一个**尾指针 `r`**，始终指向链表的最后一个结点。

**核心特性：**
- 借助尾指针，插入操作无需从头遍历寻找尾部，时间复杂度为 O(1)。
- **重要特性**：尾插法能**保持元素的插入顺序**（例如依次插入 10, 20, 30, 40，结果依然是 10 -> 20 -> 30 -> 40）。

**提供的操作：**
- `InitList`：创建头结点，返回头指针。
- `TailInsert`：在链表尾部追加新结点，同时更新尾指针。
- `Print`：遍历并打印链表。
- `Length`：统计数据结点个数（不含头结点）。
- `DestroyList`：释放所有结点内存。

## 编译与运行

本项目使用标准 C 语言编写（C99 及以上），已在 Visual Studio 和 GCC 环境下测试通过。

**使用 GCC 编译（Linux / macOS / MinGW）：**
```bash
gcc SqList.c -o SqList
./SqList

gcc LinkList_HeadInsert.c -o LinkList_HeadInsert
./LinkList_HeadInsert

gcc LinkList_TailInsert.c -o LinkList_TailInsert
./LinkList_TailInsert
